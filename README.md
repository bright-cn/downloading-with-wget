## 什么是 Wget？

[`wget`](https://www.gnu.org/software/wget/) 是一款多功能命令行工具，旨在通过 HTTP、HTTPS、FTP、FTPS 和其他多种协议从互联网下载内容。大多数基于 Unix 的系统都预装了该工具，Windows 环境也可使用。

## Wget 相较于 Python requests 包的优势

与其依赖 [requests](https://www.bright.cn/faqs/python-requests/what-is-requests-used-for) 等库，不如将 `wgen` 集成到 Python 项目中，理由十分充分：

- 与 requests 相比，支持更多协议
- 可在下载中断后继续下载
- 提供限制带宽占用的选项
- 支持在文件名和网络路径中使用通配符模式
- 通过 NLS 提供多语言消息
- 可将已获取文档中的绝对 URL 转换为相对链接
- 支持与 HTTP/S 代理集成
- 维持持久 HTTP 连接
- 支持后台/无人值守下载操作
- 在镜像时根据文件时间戳智能判断是否需要重新下载
- 以指定深度递归下载链接资源
- 内置对 robots.txt 指令的遵循机制（详见我们的 [robots.txt 网页爬虫指南](https://www.bright.cn/blog/how-tos/robots-txt-for-web-scraping-guide)）

与标准 Python HTTP 库相比，这些功能只是 `wget` 强大能力的一部分。特别值得一提的是，`wget` 能够浏览 HTML 页面，并跟踪和下载其中引用的文件。此功能使其特别适合网页爬虫操作。

接下来，我们来看看如何在 Python 中实现 `wget`。

## 在 Python 中执行命令行指令

按照以下流程创建一个能够执行 `wget` 命令的 Python 脚本。

### 设置要求

继续操作前，请确保系统中已正确安装 `wget`。安装方式因操作系统而异：

- Linux 系统通常默认包含 wget；如果没有，请通过所用发行版的包管理器安装
- Mac 用户可以[使用 Homebrew 安装 `wget`](https://formulae.brew.sh/formula/wget)
- Windows 用户应下载 [`Wget` Windows 二进制文件](https://gnuwin32.sourceforge.net/packages/wget.htm)，将其放入某个目录，然后把该位置（例如 C:\\Program Files (x86)\\Wget）添加到[系统 PATH 变量](https://www.architectryan.com/2018/03/17/add-to-the-path-on-windows-10/)中

你还需要安装 Python 3 或更高版本。请[下载安装程序](https://www.python.org/downloads/)并完成安装流程。

使用 [PyCharm Community Edition](https://www.jetbrains.com/pycharm/download/) 或[安装了 Python 扩展的 Visual Studio Code](https://code.visualstudio.com/docs/languages/python) 等开发环境，可改善你的编码体验。

### 创建 Python 环境

创建一个带有专用[虚拟环境](https://docs.python.org/3/library/venv.html)的新 Python 项目：

```sh
mkdir wget-python-demo

cd wget-python-demo

python -m venv env
```

`wget-python-demo` 文件夹将作为项目目录。

在 IDE 中打开此位置，创建一个 `script.py` 文件并添加以下初始内容：

```python
print('Hello, World!')
```

这个简单脚本目前只会在控制台输出“Hello, World!”，但我们很快会为其添加 `wget` 功能。

单击 IDE 中的运行按钮，或输入以下命令来测试脚本：

```sh
python script.py
```

你应该会看到以下输出：

```
Hello, World!
```

现在，我们来实现 `wget` 集成。

**创建用于执行 CLI 命令的函数**

从 Python 运行终端命令最直接的方法是使用 [`subprocess`](https://docs.python.org/3/library/subprocess.html) 模块。这个标准库组件支持启动新进程、连接其输入/输出/错误流，并获取退出代码，具备从 Python 内部执行终端命令所需的全部功能。

以下展示如何利用 subprocess 的 [`Popen()`](https://docs.python.org/3/library/subprocess.html#subprocess.Popen) 方法，在 Python 中运行 `wget` 命令：

```python
import subprocess

def execute_command(command):
    """
    Execute a CLI command and return the output and error messages.
    
    Parameters:
    - command (str): The CLI command to execute.
    
    Returns:
    - output (str): The output generated by the command.
    - error (str): The error message generated by the command, if any.
    """
    try:
        # execute the command and capture the output and error messages
        process = subprocess.Popen(command, shell=True, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
        output, error = process.communicate()
        
        output = output.decode("utf-8")
        error = error.decode("utf-8")
        
        # return the output and error messages
        return output, error
    except Exception as e:
        # if an exception occurs, return the exception message as an error
        return None, str(e)
```

`Popen()` 会在操作系统中将你指定的命令作为新进程启动。`shell=True` 参数可确保该方法使用系统的默认 shell 环境。

将此函数添加到 script.py 文件中。现在，你可以像这样在 Python 中执行任何命令行指令：

```python
output, error = execute_command("<CLI command string>")

if error:
    print("An error occurred while running the CLI command:", error)
else:
    print("CLI command output:", output)
```

## 结合 Python 使用 Wget 的实际应用

标准的 `wget` 命令结构如下：

```sh
wget [options] [url]
```

其中：
- `[options]` 表示用于修改 `wget` 行为的各种标志和参数
- `[url]` 指定要下载内容的位置，可以是直接文件链接，也可以是包含多个资源的网页

> **注意**：
>
> Windows 用户应使用 `wget.exe`，而不是 `wget`。

接下来，我们来了解通过 Python 使用 `wget` 的几个实际场景。

### 获取单个文件

要使用 `wget` 下载 http://lumtest.com/myip.json，基本命令如下：

```sh
wget http://lumtest.com/myip.json
```

在 Python 中，命令如下：

```python
output, error = execute_command("wget http://lumtest.com/myip.json")
```

打印输出后会显示类似以下内容：

```
--2024-04-18 15:20:59-- http://lumtest.com/myip.json
Resolving lumtest.com (lumtest.com)... 3.94.72.89, 3.94.40.55
Connecting to lumtest.com (lumtest.com)|3.94.72.89|:80... connected.
HTTP request sent, awaiting response... 200 OK
Length: 266 [application/json]
Saving to: 'myip.json.1'

myip.json.1 100%[=================================================>] 266 --.-KB/s in 0s

2024-04-18 15:20:59 (5.41 MB/s) - 'myip.json.1' saved [266/266]
```

此输出表明：
1. URL 被解析为服务器的 IP 地址
2. 通过 HTTP 请求与指定资源建立连接
3. 服务器返回 [200 OK 状态码](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status)
4. 文件下载并保存到当前目录

你的项目文件夹现在将包含下载的 myip.json 文件。

要指定其他目标文件夹，请使用 `--directory-prefix` 或 `-P` 标志：

```python
output, error = execute_command("wget --directory-prefix=./download http://lumtest.com/myip.json")
```

这会将文件保存到项目目录内名为“download”的子文件夹中。如果该文件夹不存在，`wget` 会自动创建。

要重命名下载的文件，请使用 `--output-document` 或 `-O` 标志：

```python
output, error = execute_command("wget --output-document=custom-name.json http://lumtest.com/myip.json")
```

这会创建名为 custom-name.json 的文件，而不是使用原始文件名。

### 抓取网页

命令结构保持不变，但 URL 改为指向网页：

```python
output, error = execute_command("wget https://brightdata.com/")
```

这会下载一个 index.html 文件，其中包含 brightdata.com 主页的 HTML 内容。

### 根据修改情况有条件地下载文件

为了节省带宽和存储空间，你可能只想下载自上次下载后发生过变化的文件。为此，`wget` 提供了[文件时间戳功能](https://www.gnu.org/software/wget/manual/html_node/Time_002dStamping.html)。

`--timestamping` 选项会让 `wget` 比较本地文件与服务器文件的时间戳。如果本地文件的时间戳与服务器版本相同或更新，`wget` 就会跳过下载。

时间戳处理流程如下：

1. 使用 `--timestamping` 或 `-N` 选项时，`wget` 会获取远程文件的时间戳
2. 它会将该时间戳与本地文件的时间戳进行比较（如果本地文件存在）
3. 只有在本地文件不存在或其时间戳早于服务器版本时，才会执行下载

对于 HTTP 资源，时间戳功能会检查 HEAD 请求后返回的 [Last-Modified](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Last-Modified) 标头。`wget` 还会检查 [Content-Length](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Content-Length) 标头以比较文件大小。如果大小不同，无论时间戳信息如何，都会下载文件。请注意，Last-Modified 是可选标头；如果没有该标头，`wget` 会自动下载文件。

在 Python 中按以下方式实现时间戳功能：

```python
output, error = execute_command("wget --timestamping https://brightdata.com")
```

如果你之前下载过 index.html，将会看到类似以下消息：

```
--2024-04-18 15:55:06-- https://brightdata.com
Resolving brightdata.com (brightdata.com)... 104.18.25.60, 104.18.24.60
Connecting to brightdata.com (brightdata.com)|104.18.25.60|:443... connected.
HTTP request sent, awaiting response... 304 Not Modified
File 'index.html' not modified on server. Omitting download.
```

同一机制也适用于 [FTP 下载](https://www.gnu.org/software/wget/manual/html_node/FTP-Time_002dStamping-Internals.html)。

### 恢复中断的下载

默认情况下，如果下载期间连接失败，`wget` 最多会自动重试 20 次。要手动恢复未完成的下载，请使用 `--continue` 或 `-c` 选项：

```python
output, error = execute_command("wget --continue http://lumtest.com/myip.json")
```

### 镜像整个网站

`wget` 最强大的功能之一是递归下载，让你可以通过一条命令抓取整个网站。

`wget` 会从你指定的 URL 开始解析 HTML，并跟踪在 `src` 和 `href` 属性或 CSS `url()` 值中找到的链接。如果这些引用文件是 HTML/文本文档，`wget` 会继续解析并跟踪其中的链接，直至达到你设置的深度限制。此递归过程遵循[广度优先搜索模式](https://www.geeksforgeeks.org/breadth-first-search-or-bfs-for-a-graph/)，先下载深度为 1 的资源，再继续处理深度为 2 的资源，以此类推。

递归下载的关键选项包括：

- `--recursive` 或 `-r`：启用对链接资源的递归下载，包括图片、样式表、脚本等。文件会整理到以目标域名命名的文件夹中。
- `--level=<depth>` 或 `-l=<depth>`：定义跟踪链接时的最大递归深度。例如，`--level=1` 只会下载起始 URL 直接链接的页面。默认限制为 5，以防过度爬取。使用 0 或“inf”可设置为无限深度。要确保无论深度如何都下载所有对页面显示至关重要的资源，请添加 `-p` 或 `--page-requisites` 选项。
- `--convert-links` 或 `-k`：调整已下载 HTML 文件中的链接，使其指向本地副本，而不是原始 URL。这样便可离线浏览下载的内容。

要以深度限制 1 递归下载 Bright Data 网站，并将所有链接转换为本地引用，请执行：

```python
output, error = execute_command("wget --recursive --level=1 --convert-links https://brightdata.com")
```

完成后，你将获得一个 brightdata.com 文件夹，其中包含递归深度为一层的网站本地副本。

## 将 Wget 与 Python 集成的优点和局限性

接下来，我们分析一下结合 Python 使用 `wget` 的优点和缺点。

**优点**

- 通过 subprocess 模块即可轻松与 Python 集成
- 功能丰富，包括递归下载、自动重试、时间戳等
- 可通过一条命令镜像整个网站
- 内置 FTP 支持
- 支持代理服务器集成
- 能够恢复中断的下载

**局限性**

- 输出是下载的文件，而不是可直接在 Python 代码中使用的字符串变量
- 需要使用 [Beautiful Soup](https://www.bright.cn/blog/how-tos/beautiful-soup-web-scraping) 等额外解析器，从下载的 HTML 中提取特定元素

## 使用代理服务器增强 Wget

使用 `wget` 下载时，一个常见问题是请求可能被拦截。这是因为 `wget` 请求通常会被识别为自动化流量。为了防范此类自动访问，许多网站会实施各种限制，包括地理封锁、速率限制和反爬虫措施。

将代理服务器与 `wget` 结合使用，是绕过这些限制的有效方案。代理充当你的系统与互联网之间的中介，通过其他 IP 地址路由流量。这有助于隐藏你的真实 IP，并绕过网站的多种限制。

有关详细说明，请参阅我们的[如何将代理与 `Wget` 配合使用](https://www.bright.cn/blog/how-tos/wget-proxy)指南。
